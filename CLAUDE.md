## Залізні правила
1. **Власник — не програміст:** роби все сам, звітуй простою людською мовою, без коду й технічного жаргону.
2. **Ніколи не використовувати markdown-таблиці у відповідях** (правило no-markdown-tables.md).
3. **Товари завжди нагорі** — опис сайту, умови та гарантії внизу над футером.
4. **Миттєвий скрол нагору:** обов язково слухати touchend для мобільних, швидка анімація scrollToTopAnimated(360) з easeOutQuint, відступ 140px над плаваючим кошиком 74px.
5. **Пуш у ВСІ 5 репозиторіїв:**
   git push origin main && git push as_repo main && git push urbangrid main && git push urbangrid_ua main && git push urbangridv main
6. **Завжди перевіряти живий сайт** на HTTP 200 перед фінальним звітом власнику.
